Birdy Flap

The 2014 Game Factory classic, rebuilt for the modern web. No plugins — just flap.

Score 0  ·  Best 0

Click, tap, or press Space / ↑ to flap. Fly through the pipes — don't clip one!

Game Description: "Birdy Flap" was designed and created as a technical demo to highlight what games might be created at Net Byte's "Game Factory". It's a simple clone of the popular, addicting game "Flappy Bird". The objective is to successfully jump the bird through each column without hitting them — or it's game over!

Platform Availability: Any modern web browser (Chrome, Firefox, Safari, Edge) — desktop and mobile. No plugins required.

Game Engine: HTML5 Canvas + JavaScript (2026 remake). The original was built in Unity 4.6 and needed the Unity Web Player plugin, which browsers stopped supporting years ago — so the game has been rebuilt from scratch to keep it playable.

Game Modes: Single-player only  ·  Genre: Arcade / Adventure

Original Release Date: 12/30/2014  ·  Price: FREE!
